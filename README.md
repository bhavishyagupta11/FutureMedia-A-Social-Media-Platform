# FutureMedia v1.0

> **FutureMedia Version 1.0 – Enterprise Production Ready**

## Overview
FutureMedia is an enterprise-grade, massively scalable social intelligence platform. This repository contains the complete microservice architecture, integrating a React frontend, a Node.js backend, and a Python intelligence service, entirely backed by Redis queues, MongoDB replicas, and robust Docker orchestration.

## Tech Stack
- Frontend: React, Vite, React-Query, TailwindCSS
- Backend: Node.js, Express, Mongoose, Zod
- Caching/Queues: Redis, BullMQ
- Intelligence: Python, FastAPI
- Security: Helmet, Bcrypt, CORS, JWT

## Run the Application
```bash
docker-compose up --build
```
